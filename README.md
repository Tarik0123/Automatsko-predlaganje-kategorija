# Automatsko-predlaganje-kategorija
Model automatski predlaze odgovarajuce kategorije za svaki novi proizvod na osnovu njegovog naziva

Automatske_kategorije.ipynb je radnsa sveska u kojoj se prave i treniraju modeli, i posilje cuvaju u train_model.py
train_model.py cuva trenirani model
predict_category.py je file u kojem se model tesitra.

Samo pokrenite predict_category.py i upisite ime proizvoda u terminal.
